# Chapa Quente Burger Co. 🍔🔥

> Smash na chapa, sabor sem pressa — Hamburgueria artesanal no Rio de Janeiro.

Website institucional responsivo e cardápio digital interativo da **Chapa Quente Burger Co.**

## 🚀 Tecnologias Utilizadas

- **HTML5** (Semântica moderna, Schema.org para SEO local e tags Open Graph)
- **CSS3** (Design responsivo, variáveis CSS, animações suaves e modo escuro)
- **JavaScript (Vanilla)** (Navegação dinâmica, interatividade e integração com WhatsApp)

## 📁 Estrutura do Projeto

```text
├── assets/
│   └── images/          # Imagens dos burgers, combos, sobremesas e identidade visual
├── css/
│   └── style.css        # Folha de estilos completa e responsiva
├── js/
│   └── main.js          # Scripts de interação e filtros
├── cardapio.html        # Página completa do cardápio online
├── index.html           # Página inicial institucional
└── README.md            # Documentação do projeto
```

## 🛠️ Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/pamellafreitas/chapa-quente.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador web ou utilize a extensão **Live Server** no VS Code.
